Why SQL injection got fixed and prompt injection hasn't

The bug is the same: the server glues the user's text into a command, so the database can't tell where the developer's code ends and the user's data begins. That's Level 1 of the lab.

SQL has a real fix: parameterized queries send the command and the data separately. The ? is a slot that can only ever hold data, so no input can change what the command does.

LLMs have no equivalent. A system prompt and a user message both end up as one stream of text the model reads. Instruction hierarchies and delimiters help, but they're the model's habits, not a hard wall. That's why every level in the lab could eventually be beaten.
